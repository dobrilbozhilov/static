# Java наръчник за интервю

Документите в `md/` са източникът на истината. Билдът ги събира в една HTML страница с меню, по една
страница на документ, Mermaid диаграми и highlight на кода.

```bash
cd java
npm install
npm run build        # създава dist/index.html и dist/pages/*.html
make run             # http://localhost:8087, пребилдва при промяна
```

Редът на страниците и модулите са в `manifest.json`: езикът и JVM, колекции, конкурентност,
Spring Boot под капака. Всеки документ: кратко определение (първият абзац), за какво се ползва,
диаграма, минимален пример с коментари, въпроси на интервю, капани и свързани документи.

Самостоятелните Java примери са пуснати с OpenJDK 21 (`java File.java`) и изходът в коментарите е
реалният. Spring примерите (модул 4) не са компилирани; механизмът на proxy е показан с чиста Java.
