# Node.js наръчник за интервю

Документите в `md/` са източникът на истината. Билдът ги събира в една HTML страница с меню, по една
страница на документ, Mermaid диаграми и highlight на кода.

```bash
cd nodejs
npm install
npm run build        # създава dist/index.html и dist/pages/*.html
make run             # http://localhost:8085, пребилдва при промяна
```

Редът на страниците и групите (модулите) са в `manifest.json`. Всеки документ следва една структура:
кратко определение (първият абзац), за какво се ползва, диаграма, минимален пример с коментари,
въпроси на интервю с отговори, капани и свързани документи. Без интерактивни секции.

Примерите с ред на изпълнение са проверени с Node 24 (CommonJS, освен ако не е казано друго).
