# Spring Boot наръчник

Документите в папка `md/` са източникът на истината. Билдът ги събира в една HTML страница с меню,
по една страница на документ, Mermaid диаграми и highlight на Java кода.

```bash
cd spring-boot
npm install
npm run build        # създава dist/index.html и dist/pages/*.html
```

Редът на страниците, групите и кратките имена в менюто са в `manifest.json`. Всеки документ започва с
`# Заглавие`, после един lead параграф, после номерирани секции `## 1. ...`, като последните три са
"Капани", "Чеклист" и "Свързани документи". Линк към друг документ се пише с името на файла му,
например `[Валидации](Validation.md)`.

Таргет: Java 21, Spring Boot 3.5, PostgreSQL.
