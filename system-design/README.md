# Билд на приложението

Документите в папка `md/` са източникът на истината. Този билд ги събира в една HTML страница
с меню, по една страница на документ, и рендерира Mermaid диаграмите в браузъра.

```bash
cd system-design
npm install
npm run build        # създава dist/index.html
```

Редът на страниците и кратките имена в менюто са в `manifest.json`.

## Каталог с патерни

Страницата "Каталог с патерни" (`#catalog`) и страниците на отделните патерни (`#cat-<slug>`) се описват в
`catalog.json`: семейства с цвят по `id` (CSS променлива `--fam-<id>` в `template.html`), а във всяко семейство
патерни със `slug`, `name`, `tagline` и `related` (slug-ове на свързани патерни, рендерирани като чипове в края на страницата).
Текстът на всеки патерн е в `md/catalog/<slug>.md` и следва една и съща структура: lead, "Представи си", "Проблемът, който решава",
"Как работи", "Кога да го ползваш", "Капани" и по желание "Къде е в наръчника". Линк към друг патерн се пише като `[Retry](retry.md)`,
линк към документ от наръчника с името на файла му, например `[Node.js патерни](Design_Patterns_Node_Architecture.md)`.
